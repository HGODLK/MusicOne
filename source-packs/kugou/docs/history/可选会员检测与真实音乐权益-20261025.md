# 酷狗可选会员检测与真实音乐权益

本轮修正上一轮 `143e6778` 对会员类型的过宽解释，保留 `1.0 / code1`。需配套本轮可选会员检测 SDK 与宿主，公共和音源包分开提交，先不构建。

配套公共提交：`d9db5283`（默认关闭的三态接口及必要接线）。

入口主动实现 `SourceMembershipProvider` 并提供 `KugouMembershipDeclaration`。只读属性读取当前完整凭证对应的有效缓存，不联网；显式检测沿包内账号捕获、IO及失效检查查询。未初始化、未登录、无音乐会员或失败均不能确认会员，宿主按已声明映射为 unknown/null。

会员仍从既有 3116 身份的 `get_my_info` 读取，但只将 `m_type=1..4` 或已核对的普通音乐畅听位 `user_type & 256` 判为音乐权益。通用 `vip_type`、SVIP/超级 VIP 展示位 `8/16` 不能统一替代音乐包和歌曲自身的授权；仅有这些身份而缺少可确认音乐权限时保持未知。`m_type=0` 可在包内记为明确无音乐包，公开检测按用户指定规则归为 unknown。

歌曲继续保留原始收费与购买归属，只有已核对的音乐权益才消除相应 VIP 提示；特殊曲目、单独购买及实际媒体可用性仍走原有单曲与换票结果。没有另造畅听接口、修改取址/音质/回退/时长上报或页面布局。

认证 revision 仅表示原有会话代次，不再叠加会员查询修订，避免正常会员查询完成后被运行时误当成换号取消。换号、退出与移除仍拒绝旧结果。
