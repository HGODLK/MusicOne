# 酷狗真实听歌时长与强制登录（2026-10-25）

本轮音源版本为 `versionCode=1`／`1.0`。用户已授权新增默认不启用的可选播放会话接口，并在 QQ、酷狗包内同步真实听歌时长；后续明确要求酷狗强制登录。公共接口及宿主由独立公共提交提供，本包需配套该 SDK／宿主。

## 接入与时长

- `KugouSourcePlayback` 主动实现 `SourcePlaybackSessionProvider`，提供独立 `KugouListeningReporter`；不再把原 `reportPlayed` 最近播放入口当成听歌时长接口，原云端历史上报保留。
- 只使用宿主会话累计 `playedMs`，不使用歌曲总长、播放位置、倍速换算或拖动距离。PROGRESS／RESUME 不触发时长写请求；PAUSE、END 读取服务端真实 `d_sec`，再提交自上次写请求以来的整秒差额。毫秒余数在同一会话保留到下次结算。
- START 固定完整账号凭证及包内 generation。后续事件核对 sessionId、sequence、歌曲身份、真实累计量及原账号；换号、退出或凭证变化后丢弃旧会话，不向新账号补交旧时长。重复及倒序事件不再次记账。
- 基线读取失败时可在下次结算重读；写请求已经开始而结果不明确时，消耗该段差额，不自动重放，避免网络超时后重复入账。CSCC 事件与等级时长同步分别处理，某一项失败不冒充另一项成功。

## 平台协议

现包 `KugouProtocol.appId=3116`，登录和已有接口使用概念版身份及密钥；本轮继续使用相同身份、当前 `clientVersion=11440`，没有更换成普通版客户端身份。

- 时长采用 `https://userinfo.user.kugou.com/v2/get_grade_info`：先查询真实累计基线，随后提交 `d_sec`／`diff_sec` 及 RSA 校验；`y_type`／`m_type` 沿用同一 3116 公开实现的默认值 `0`，没有根据音频可播放权益推断这些字段。
- CSCC 经 `/v3/qrydid`、`/v2/gen`、`/v2/post` 建立账号设备会话，发送实际开始与结束事件；完成和中断分别对应“完整播放”与“中断播放”，`duration` 为真实收听毫秒。只有开始时存在完整歌曲编号且开始事件已确认，才发送对应结束事件；初始身份不完整或开始失败时，仍单独结算真实时长，不发送孤立结束事件。
- 机型、系统、显示尺寸和可取得的本机地址来自实际 Android 环境；没有复制参考报文中的页面位置、触摸轨迹、会员字段、固定机型或固定屏幕。会话密钥／签名／凭证不写日志。

参考公开实现：[KuGouMusicApi 等级时长](https://github.com/MakcRe/KuGouMusicApi/blob/main/module/user_grade_info.js)、[KuGouMusicApi CSCC](https://github.com/MakcRe/KuGouMusicApi/blob/main/module/user_listen_report.js)、[MoeKoeMusic 播放器接线](https://github.com/MoeKoeMusic/MoeKoeMusic/blob/main/src/stores/listenTime.js)。协议代码均留在本包。

## 强制登录

manifest 与入口 descriptor 同步声明 `requiresLogin=true`。宿主现有登录判断继续适用；由于自定义根页会直接调用包内 Content，另在包内 `KugouRequiredLogin` 检查真实认证状态，游客、过期和缺少账号的会话均复用现有 `authenticationPage`，认证后才显示原首页／我的／搜索。相邻不可见根页不重复创建扫码任务。通过现有账号偏好变化监听登录／退出，无需公共框架改动或新增登录页面／动效。

包内既有 `KugouPackageState.request` 同时核对完整凭证及账号一致性，搜索、目录、歌词、播放解析和音质查询等业务入口统一要求登录；保存队列、直接取源及缓存恢复后的远端取源不能绕过 UI 门禁。`account()` 与业务门禁复用同一纯本地条件：正整数账号、凭证账号与本地账号一致、token 与 mid 完整；缺失或不匹配时认证状态为游客并展示已有登录页，不新增联网验票。登录、短信、扫码和会话迁移沿原独立认证入口执行。

## 本轮验证边界

已补充会话差额、暂停恢复、拖动位置无关、重复／倒序、换号、失败不重放、真实协议正文及强制登录入口的回归源码，并做静态差异检查。按用户“先不构建”要求，没有执行 Gradle、单测或打包，没有向实际账号发出写请求，没有安装或操作设备。真实账号入账以及是否同步普通版展示，仍需后续登录账号播放后读回平台数据确认。
