## 已修改

- `KugouCollectionTrackSnapshot`：完整快照只保留原始行和排序索引，按请求页沿原映射转换歌曲，不保留两套全量权益对象。摘要按原输入格式增量计算，继续使用 `kgct1` 游标；曲数、全局 ID 降序、资源字段和权益规则不变。
- `KugouCollectionTracks`：内存只保留最近读取的一张完整快照，其余已验证快照仍完整保存在磁盘。换号及时清理，不删歌、不限制总曲数。分页接收与解析均检查请求取消及账号归属。
- `KugouCollectionTracksStore`：新 schema2 为头部加逐行歌曲的原子文件，生产写入不再构造整单 JSON 字符串或 UTF-8 大数组。支持旧 schema1 读取；旧格式第一次读取仍需解析原来的整段 JSON，不宣称这条兼容路径已完全流式化。新格式缺行、计数不符或解析失败不能覆盖有效快照。
- `KugouCollectionClient`：增加逐页消费接口；目录封面扫描只保留最新加入记录的封面，不再借封面请求建立歌曲快照。仍扫描全部分页确认最大 ID，不假设服务端返回顺序。
- `KugouPackageState`、`KugouSourceEntry`：换账号、退出与关闭音源时释放内容缓存。同账号正常续期不清空内容；原认证、播放请求和权益规则不变。
- `KugouHomeController`、`KugouHomeCollections`、`KugouSourceCatalog`：及时释放旧首页、已保留详情视图及目录缓存，取消旧首页任务；目录回填再次校验原请求账号，避免清理后旧响应重新常驻。
- 三处包版本与打包文件名统一为 code39／0.2.27。没有修改 SDK、runtime、app、其他音源或播放器。
