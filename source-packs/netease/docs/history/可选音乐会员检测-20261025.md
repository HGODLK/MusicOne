# 网易云可选音乐会员检测

入口主动提供 `SourceMembershipProvider`，原版本及包身份保持，需配套本轮 SDK／宿主。B站与示例没有声明；所有主／补充音源都遵循未声明 false、确认音乐会员 true、声明但无会员或未知为 unknown/null。

配套公共提交：`d9db5283`（默认关闭的三态接口及必要接线）。

新检测器只读属性不联网，显式查询复用现有账号接口并核对完整凭证、账号及代次。同账号刷新沿既有 refreshing 语义，不把会员资料变化伪装成会话切换；成功资料五分钟核对，普通失败短暂复用 unknown，同屏并发合并。

包内新增独立的确认字段，只采纳有依据的当前音乐包 `vipType=10` 和黑胶 `11`，未知枚举不猜测授权。类型依据为 [cloudmusic 作者的 User.vipType 说明](https://pypi.org/project/cloudmusic/)。原 hasVipAccess、歌曲 fee/privilege、取址、音质和歌词逻辑不改；新声明不从旧持久化布尔值反推已确认会员。

补充已知类型、未知类型及原账号元资料保持的回归源码。完成静态差异检查，未编译、运行测试、构建或操作设备，不升级版本。
