# QQ 可选会员检测声明

保持 `1.0 / code1`，入口主动提供 `SourceMembershipProvider`，需配套本轮 SDK／宿主。未增加其他业务或修改原歌曲权益、播放、音质和时长协议。

配套公共提交：`d9db5283`（默认关闭的三态接口及必要接线）。

新检测器只读属性按当前凭证与认证代次读取已确认结果，不通过原 `readSession` 触发联网。显式检测复用 `QqMembershipClient` 的真实音乐会员协议；只有有效音乐会员为 true，无会员／资料不足／普通失败为 unknown/null。成功按原会员查询刷新时机复用，失败短暂复用 unknown，同屏并发合并；账号或会话变化后拒绝旧结果。原歌曲权益缓存策略保持。

补充默认无请求、并发合并、非会员 unknown、失败替换旧确认、换号和真实到期回归源码。只做静态差异检查，未运行测试、编译、构建或操作设备。公共与音源包分开提交，不升版本号。
