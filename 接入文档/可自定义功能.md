# 可自定义功能

宿主兼容与安装规则见 [README](README.md#最低宿主版本) 与[完整规范](Agent音源接入完整规范.md#installation)；用到的宿主接口须满足其[最低宿主门槛](Agent音源接入完整规范.md#host-thresholds)。

音源可以提供业务数据和操作，也可以决定内容页面如何组织。MusicOne 提供可直接使用的公共整页，也提供能放进自定义布局的公共组件；两者可以混合使用。本文介绍可选范围，具体接口和接线见 [Agent 音源接入完整规范](Agent音源接入完整规范.md)，接入步骤见 [用法](README.md)。

## 页面可以怎样组织

| 方式 | 适合的需求 | 音源负责什么 |
| --- | --- | --- |
| 补充音源逐页选择 | 按首页、链接、内容、集合列表／详情、账号、设置分别选择默认、自定义或关闭 | 提供 SourceSupplementalPageProvider 并保持 `useCustomPages=false`；未配置的页面使用默认公共页，仍需对应业务服务。CUSTOM 可复用全部公共整页及组件；失败后仅显式允许 allowPublicFallback 且具备公共能力时，用户才能选择回公共页。 |
| 使用公共模板 | 采用 MusicOne 的默认页面组织和交互 | 设置 `useCustomPages=false`，提供真实的数据、业务操作，以及需要的认证和设置页面。 |
| 自定义入口，复用公共整页 | 想自己组织入口和导航，部分页面继续使用现成界面 | 主音源或未实现逐页接口的补充音源设置 `useCustomPages=true`，安排入口、内部导航和返回；需要时打开或嵌入完整公共页面。 |
| 自定义布局，组合公共组件 | 想改变首页分区、卡片组合或详情排版，同时沿用公共控件 | 主音源或未实现逐页接口的补充音源设置 `useCustomPages=true`，实现逐页接口的补充音源选择 CUSTOM；编排组件、提供数据并连接操作，也可混入自有内容。 |
| 自行实现内容页面 | 需要公共模板和组件无法表达的业务交互 | 主音源或未实现逐页接口的补充音源设置 `useCustomPages=true`，实现逐页接口的补充音源选择 CUSTOM；实现自有页面，通过公开接口使用宿主能力。 |

自定义页面可以混用公共整页、功能组件和基础组件。主音源及未实现逐页接口的补充音源由 `useCustomPages` 决定默认页面组织者；实现 `SourceSupplementalPageProvider` 的补充音源必须保持 false，通过页面策略选择页面。公共账号页需要 authentication，仅提供认证界面还不够；其他公共页面也须提供对应的内容、集合或设置服务，详见完整规范的 [逐页页面策略](Agent音源接入完整规范.md#simple-supplemental)。

## 完整播放器与开页动效

主音源可通过可选接口提供完整播放器页面。接口约定和宿主职责见下文；编译及单元测试通过不代表真实设备、播放业务和动画已完成验收，接入前应按对应验收项验证。

主音源可以独立提供 `SourcePlayerUiProvider`，自行设计播放器布局与打开入场效果，无需改变 `useCustomPages`。`SourcePlayerUiDeclaration` 必填手机竖屏、平板、手机横屏支持声明，以及打开动画时长、bar 是否参与和共享元素集合；手机竖屏与平板至少支持一种。未支持形态使用原生；已支持形态出现组合、布局、绘制或主动上报错误时保留错误页，不能借故障悄悄切回原生播放器。

可共享元素限定封面、标题、歌手和播放暂停。包用 `context.SharedElement` 包住自己真实绘制的目标 UI，宿主负责从当前底部栏源位置向该目标运动；包可读取统一进度编排背景、歌词和操作区入场。底部胶囊／bar 外观不开放，收起动画、返回和手势仍归宿主。

声明共享的文字缺失时需显示真实占位或保留非零布局；空文字不能作为有效共享目标。示例对空标题和空歌手分别使用显示占位，不改变曲目原始资料。

内容避让使用 `context.safeDrawingInsets` 的绝对 `left/top/right/bottom`，配合 `Modifier.absolutePadding`；宿主已合并安全绘制区、刘海和瀑布屏边距并转换手机左右横屏坐标，平板也直接使用。可保留满幅背景，不叠加仍使用竖屏 Activity 原始边距的 `.safeDrawingPadding()`。

包读取 `snapshot`、带歌曲及播放代际的 `timeline`、形态和过渡状态，经 `actions` 调用受控动作；拖动进度须携带同一时间线的 `trackId/generation`。歌词使用 `context.Lyrics` 复用宿主视图及时钟；包不创建第二个播放器、歌词计时器、队列或音质解析流程。详情及示例见 [完整规范](Agent音源接入完整规范.md#player-ui)。

宿主“关闭横屏播放页”设置仅将内置手机播放页固定为竖屏，不影响平板或音源自定义播放页；自定义播放页仍按声明选择支持的形态。

## 可以直接复用哪些公共页面

公共整页适合直接采用现有页面的布局和交互。音源提供对应业务服务，公共页面负责按这些服务展示数据、处理已有交互；复用页面不会自动补齐平台协议。

| 公共页面 | 能复用的内容 |
| --- | --- |
| 主音源首页 | 按公开发现服务和首页配置展示推荐内容、歌曲与歌单等分区。 |
| 我的 | 账号资料、我喜欢的音乐、创建与收藏歌单等资料库内容，按音源实际能力展示，未声明的分区直接不显示；最近播放需 `supportsRecent=true` 才显示，也可通过可选分区声明单独隐藏。 |
| 完整搜索 | 搜索输入、结果与详情入口；可以带初始关键词打开并直接提交查询。当前公共主搜索支持歌曲、歌单、歌手、专辑，内容类搜索需自定义页面处理。 |
| 歌单详情 | 歌曲列表、列表内搜索、排序、播放与随机播放、多选、批量操作、分页重试、工具栏及封面过渡；远端收藏与编辑仍由音源实现。 |
| 歌手详情、专辑详情 | 实体资料、歌曲及关联集合；歌手内搜索、排序和关注按实际支持接入。 |
| 每日推荐、最近播放、相似推荐 | 直接打开对应完整列表或推荐页，使用音源提供的真实数据。 |
| 补充音源模板 | 链接解析、内容详情、子条目选择、远端集合、播放、导入和订阅等界面。可直接进入首页、账号、集合列表、链接解析、指定集合或指定内容。 |
| 认证、音源设置入口 | 主音源及未实现逐页接口的补充音源通过公共页面入口打开认证页或设置页，缺少独立服务时回到 `Content` 的 `authentication`／`settings` 路由。实现逐页接口的补充音源遵循 ACCOUNT／SETTINGS 页面策略；默认账号页只使用真实认证服务，不回到 Content。登录协议仍由音源实现，这里的设置不是应用全局设置。 |

公共整页有两种主要用法：**直接打开**一个公共页面，或将它**嵌入**自己的页面布局。对应入口是 `pages.open` 和 `pages.Content`；需要独特排版时，也可以只使用下一节的组件。

主音源的首页和“我的”还可通过可选的一级页入口复用公共根页，避免额外的返回包装；自定义主根页列表可接入宿主页头的滚动联动。公共整页在配套宿主中保留原导航、返回和动效。补充音源的自定义入口有独立的返回规则，不直接套用主音源根页的页头、底栏约定。

## 可以组合哪些公共组件

公共组件用于自己编排页面。可以只使用一张卡片，也可以组合完整歌曲列表、工具栏和推荐分区；音源提供对应数据和事件，公共组件保留已有展示与交互。下面按用途列出常用组件，名称方便在完整规范中定位。

| 类别 | 可复用的内容 | 代表组件 |
| --- | --- | --- |
| 歌曲列表 | 歌曲列表及菜单容器、列表内搜索定位、排序、多选、选择行和批量工具栏；支持接入分页、加载与错误反馈 | `TrackListHost`、`TrackList`、`SearchTools`、`SortButton`、`SelectionRow`、`SelectionToolbar` |
| 首页歌曲与推荐 | 歌曲卡片、歌曲组（每组最多显示3首）、横向歌曲货架、每日推荐卡、电台卡、个性推荐、最近播放和相似推荐区块；推荐歌曲点击调用 `SourceHost.playRecommendation` 后，由宿主按“取消首页歌曲推荐替换播放队列”设置开电台或插入队列（最低宿主 code 5） | `SongCard`、`SongGroup`、`SongShelf`、`DailyCard`、`RadioCard`、`PersonalizedCards`、`RecentPlay`、`SimilarRecommendations` |
| 歌单展示 | 普通歌单卡片、列表行、推荐卡、大封面卡和横向歌单货架 | `CollectionCard`、`CollectionRow`、`RecommendationCard`、`FeaturedCard`、`CollectionShelf` |
| 资料库与实体 | 账号资料头、我喜欢的音乐入口、创建/收藏分类切换、集合入口，以及歌手或专辑的列表行和摘要 | `ProfileHeader`、`FavoritesRow`、`CollectionSegment`、`CollectionButton`、`EntityRow`、`EntitySummary` |
| 状态与提示 | 分区标题、空状态、行内消息、加载及加载更多反馈 | `SectionTitle`、`Empty`、`InlineMessage`、`Loading`、`LoadMore` |
| 基础展示与操作 | 封面、歌曲标题、歌曲角标、播放操作、按钮、操作行、表单输入和设置分组 | `Artwork`、`SongTitle`、`TrackBadges`、`PlaybackActions`、`ActionButton`、`ActionRow`、`FormField`、`SettingsGroup` |
| 搜索/设置入口与玻璃背景 | 首页搜索与设置按钮、背景采样容器及原有交互动效；页面提供需要采样的背景 | `SearchButton`、`SettingsButton`、`Backdrop` |
| 补充内容与导入 | 链接输入、内容摘要、子条目选择、导入目标、导入操作和补充账号展示 | `LinkInput`、`ContentSummary`、`ChildSelection`、`ImportTarget`、`ImportActions`、`SupplementalAccount` |
| 补充远端集合 | 远端集合卡片、列表行和详情页头 | `RemoteCollectionCard`、`RemoteCollectionRow`、`RemoteCollectionHeader` |

以上分别归属歌曲列表、首页推荐、资料库、基础控件和补充内容五类公共组件接口。组件通过 `components.forSource` 取得当前音源的作用域，不能拿另一个音源的私有页面或状态来拼装。

组合歌曲多选时，使用 `TrackListHost` 或已有公共歌曲菜单容器承接菜单与批量操作；单独放置多选工具栏不会自动创建这个容器。

每日推荐卡和个性推荐组合另有可选的 `SourceLoadedHomeComponents`，可传入真实、已加载的歌曲，复用完整来源卡过渡。歌单与歌曲须属于当前音源，其中声明的账号须与当前账号一致；只有歌曲非空且当前场景提供公共过渡上下文时才走该过渡，组件不会自行补取歌曲。原有仅传歌单资料的入口继续可用。

歌曲与歌单货架另有可选入口，可以在保留内容边距的同时使用完整横滑视口；手机和平板按各自布局提供边距。已有封面也可以通过可选能力提前准备宿主缓存，减少首次展示时的等待；该能力只读已有缓存，不下载图片，也不阻挡整个首页显示。

## 常见的混合方式

| 想实现的效果 | 可以怎样组合 |
| --- | --- |
| 自己设计首页，其他页面沿用公共界面 | 首页组合每日推荐卡、歌曲货架和歌单卡；点击后打开公共歌单、搜索、歌手或专辑详情，“我的”使用完整公共页。 |
| 自己设计歌单头部，保留完整歌曲操作 | 使用自定义封面和简介布局，下面组合公共歌曲列表、搜索、排序、多选和菜单容器。 |
| 自己设计补充音源入口，沿用导入流程 | 在自定义入口收集链接，再打开公共补充内容页；也可自己组合内容摘要、子条目选择、导入目标和操作区。 |

## 其他可自定义能力

| 功能 | 可自定义范围 |
| --- | --- |
| 推荐与搜索数据 | 首页分区内容、货架分组、每日推荐、最近与相似推荐、搜索类型、建议和热搜；`discovery` 可通过 `SourceMySectionPresentation` 声明 `showRecentInMy=false`，隐藏公共“我的”页最近播放，不等于关闭最近播放服务。公共模板的布局与分类受其现有能力限制，自定义页面可自行组织。 |
| 资料库与实体 | 歌单分区、收藏资格、创建/编辑/删除、增删歌曲、云端顺序，以及歌手/专辑资料、歌手关注；只展示真实支持的操作。 |
| 账号与设置 | 登录方式、验证流程、账号摘要和音源自己的设置页面。补充音源逐页策略的默认账号页要求 authentication；无认证页时仅显示真实摘要／退出或未提供登录页提示，不猜字段。 |
| 可选会员检测 | 入口主动提供 `SourceMembershipProvider.membershipDetector` 才启用；默认 null。未声明为 false，确认音乐会员为 true，已声明但无会员／失败为 unknown(null)。主源、补充源及歌单曲目共用，B站不声明；详情见[检测契约](Agent音源接入完整规范.md#membership-detection)。 |
| 播放与缓存策略 | 真实可用音质、默认及回退顺序、媒体取址与恢复、失败行为、音质文案、读取提示及缓存目录范围；可通过 SourceQualityCatalog 定义任意稳定音质 ID、完整及紧凑名称、说明与可选标准能力映射，多个独立档位可以映射同一标准能力；未实现该接口时使用默认音质策略。 |
| 收听时长同步 | `mediaPlayback` 额外实现 `SourcePlaybackSessionProvider` 并显式返回非 null 的 `playbackSessions` 后，接收真实播放事件和累计收听时长，按平台协议自行同步。默认关闭；暂停、缓冲及拖动跳过的进度不计，累计值不能重复当作增量。已有最近播放上报独立保留，详见 [可选播放会话](Agent音源接入完整规范.md#playback-session)。 |
| 歌词 | 在线歌词、逐字时间、整行与逐字提前量、缓存版本及部分切歌/后备策略。 |
| 颜色与展示 | 页面色、电台标签及配色、曲目主题色、歌曲角标文字及亮暗颜色、全局与歌单背景；公共歌单页只在音源支持自定义背景且歌单属于自己（`owned=true`）时提供选择与恢复背景入口。自定义页面可使用局部主题。 |
| 编辑权限 | 分别允许用户编辑歌曲资料、替换手动歌词、调整整行偏移，三项独立授权。当前开启歌曲资料编辑权限后，宿主内置歌曲收藏动作会写入本地综合歌单，不自动同步远端收藏。 |
| 补充内容 | 链接/输入解析、内容与子条目、默认选择、远端集合、曲目导入及订阅。最小接入基类与逐页策略提供可选接入方式；公开集合可显式声明稳定公开订阅身份，无需伪造账号；支持创建／刷新／取消订阅，缓存完整读取使用统一默认选择转换，预览不展开全部子条目。 |

## 使用范围与边界

- **页面和组件复用的是公共界面能力。** 认证、搜索、收藏、分页、导入等真实业务仍需音源实现；组件不会自动取得平台数据。列表要全选全部歌曲时，音源须提供取齐全部分页的能力；仅接入列表不等于自动加载全部内容。
- **公共界面按已有规则工作。** 使用完整页面时遵循其布局与交互；需要不同排版可改用组件组合。页面排序与云端改序是两项能力，远端改序还需单独支持。
- **播放器等公共执行能力仍由宿主持有。** 公共播放器、歌词展示、队列、本地资料库、缓存下载和设备音频输出不属于可任意替换的内容页面。音质文案、主题、角标和业务策略声明不等于自由改写播放器界面。
- **自定义部分仍需完成适配。** 复用组件保留公共效果，音源自己的布局、导航和返回衔接须兼顾手机/平板、明暗主题及降低动效偏好。
- **以配套 SDK 与宿主为准。** 公共页面、组件及可选扩展需要宿主实际提供；API 版本相同不代表宿主具备相同能力。发布说明须列出已验证的宿主版本或构建标识，并提供匹配的 SDK AAR。具体能力与限制见 [公共 UI](Agent音源接入完整规范.md#host-ui)、[一级根页与货架](Agent音源接入完整规范.md#root-pages-and-shelves)、[资料库扩展](Agent音源接入完整规范.md#library-extensions)。

页面关闭须由策略显式声明；缺少业务或请求失败不能冒充关闭或成功空内容。
