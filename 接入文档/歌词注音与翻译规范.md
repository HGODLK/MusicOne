# 歌词注音与翻译规范

本文说明音源包如何提供歌词翻译和注音。

翻译和注音都不需要新接口，也不需要修改 SDK：在 `SourceLyricProvider.lyrics(track)` 返回的每一行里填对应字段即可。

```kotlin
data class SourceLyricWord(val startMs: Long, val durationMs: Long, val text: String)
data class SourceLyricLine(
    val startMs: Long,
    val text: String,
    val words: List<SourceLyricWord> = emptyList(),
    val translation: String? = null,      // 翻译
    val transliteration: String? = null,  // 注音
    val parserVersion: Int = 0,
)
```

宿主从上到下显示注音、原文、翻译。用户在设置的“歌词显示内容”里选择显示范围：

| 选项 | 主歌词页 | 系统歌词 |
| --- | --- | --- |
| 原文和翻译（默认） | 原文、翻译 | 原文、翻译 |
| 原文、注音和翻译 | 注音、原文、翻译 | 原文、翻译 |
| 仅原文 | 原文 | 原文 |

切换选项只改变显示，不会重新请求歌词，所以音源包应始终返回完整数据，不要读取或猜测用户的选择。

## 翻译

`translation` 是这一行的完整译文，只有一个字符串，不带时间。

- 没有逐字数据的普通歌词也可以显示翻译。
- 宿主不合并独立的翻译文件。平台分开返回原文和译文时，由音源包按时间对齐后填入对应行。
- 没有译文时填 `null`。空白字符串、`//` 这类占位符、和原文相同的内容也要转成 `null`，宿主首次显示时不会过滤它们。

```kotlin
SourceLyricLine(startMs = 1000, text = "心の中", translation = "心中")
```

## 注音

`transliteration` 是显示在原文上方的注音，不限语言，读音由音源包提供，宿主不会自动生成。

有两种格式，宿主按内容自动识别：

| 格式 | 是否需要逐字 | 适用 |
| --- | --- | --- |
| 位置标注 `{原文|读音}` | 不需要 | 普通歌词、逐字歌词都可以 |
| 逐词制表符格式 | 必须有 `words` | 逐字歌词，读音按词一一对应 |

### 位置标注格式

把整行原文写出来，在需要注音的片段处写成 `{原文片段|读音}`，读音里的音用空格分开：

```kotlin
SourceLyricLine(startMs = 1000, text = "今日は晴れ", transliteration = "{今日|きょう}は{晴|は}れ")
SourceLyricLine(startMs = 3000, text = "心の中", transliteration = "{心|ko ko ro}の{中|na ka}")
```

- **去掉所有标注后必须与 `text` 逐字一致**（包括空格和标点），否则整句不显示注音。
- 原文片段和读音里不能出现 `{`、`}`、`|` 和换行。
- 有逐字数据时，每组注音按它覆盖的词加权点亮；没有逐字时，注音随整行一起显示。
- 旧版本宿主不认识这种格式，会整句不显示注音，不影响原文和翻译。

### 逐词制表符格式

**必须有逐字数据：** `words` 为空的行不能用这种格式。

用制表符 `\t` 分段，**段数必须等于 `words` 的数量**，每段对应一个词：

| 段内容 | 含义 |
| --- | --- |
| 空字符串 | 这个词没有注音，例如英文或标点 |
| `ko ko ro` | 这个词的注音，音之间用一个空格分开 |
| `+` | 和前一个词合用一组注音 |
| `ko@0+280` | 带时间的音：`音@偏移毫秒+时长毫秒`，宿主只取读音 |

偏移从这组注音的第一个词的 `startMs` 算起，不是歌曲时间线上的绝对时间。

### 示例

每个词一组：

```kotlin
SourceLyricLine(
    startMs = 1000,
    text = "夜に",
    words = listOf(SourceLyricWord(1000, 400, "夜"), SourceLyricWord(1400, 200, "に")),
    transliteration = "yo ru\tni",
)
```

英文词不标，两个词合标一组，音可以带时间：

```kotlin
SourceLyricLine(
    startMs = 1000,
    text = "心 love 今日",
    words = listOf(
        SourceLyricWord(1000, 600, "心 "),
        SourceLyricWord(1600, 200, "love "),
        SourceLyricWord(1800, 300, "今"),
        SourceLyricWord(2100, 300, "日"),
    ),
    transliteration = "ko@0+200 ko@200+200 ro@400+200\t\tkyou\t+",
)
```

### 显示规则

- **位置：** 同一组的音连写，居中显示在这组文字上方。想让每个字上方各有一个音，要把 `words` 拆到每个字，每个词一段。
- **放不下时：** 注音先伸到相邻文字上方，还不够才缩小这一组，不会撑开原文。
- **点亮：** 每组注音是一道光，和原文共用词的进度，从左到右扫过整组。逐音时间不影响点亮。
- **关闭逐字效果时：** 注音仍然显示，只是不再逐字变化。

### 整句不显示的情况

- 位置标注：去掉标注后与 `text` 不一致，或某组读音为空。
- 逐词格式：段数和 `words` 数量不一致，例如把整行音译 `ko ko ro no` 填给 4 个词。
- 逐词格式：第一段是 `+`。
- 逐词格式：有注音的词在 `text` 里找不到。词的文字要按顺序出现在 `text` 中，首尾空白可以不同。

宿主只检查格式，**不校验读音**，读音错位也会照常显示。

## 本地 LRC 歌词

用户导入的本地 LRC 也支持位置标注注音，两种写法都可以：

```
[00:01.00]{今日|きょう}は晴れ
[00:01.00]今天天气晴朗

[00:03.00]夜に
[00:03.00]{夜|よる}に
```

- 正文行内直接标注：显示时去掉标注，注音放在原文上方。
- 同一时间戳另起一行标注：去掉标注后与该时刻原文相同的行视为注音，其余同时刻行仍是翻译。
- 逐字行（`<mm:ss.xx>` 标记）里的标注不能跨越时间标记。

## 发布前检查

- [ ] 校验读音和原文的对应关系，对不上的句子填 `null`，不要输出错位注音。
- [ ] 标题、词曲署名等非演唱行不标注音。
- [ ] 整句都没有注音时填 `null`，不要返回全是空段的字符串。
- [ ] 翻译的空白和占位符已转成 `null`。
- [ ] 翻译或注音的生成结果有变化时，提升 `SourceLyricProvider.parserVersion`，同时写入每行的 `parserVersion`。否则用户的旧缓存不会更新。
